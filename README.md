# SOP 库 · 记忆丝（Pensieve）

> 把做完一件事的**可复用做法 / 踩过的坑**抽出来，存成 SOP，以后随时"捞出来看"。
> **做之前先查这里；做完之后回来更新这里。**

## 用法

1. **开新任务** → 先在下面找到相关 SOP，照做；
2. **做完任务** → 有新做法/新坑，就**新建或更新**对应 SOP，并在这里登记；
3. 想新建：复制 [`SOP_写作模板.md`](SOP_写作模板.md)，改名 `SOP_<主题>.md`。

## 约定

- 命名：`SOP_<主题>.md`；短而准，写「可执行步骤」和「会踩的坑」。
- 每份结构：适用 / 前置 / 步骤 / 检查清单 / 常见坑 / 参考。
- 做法变了**直接改这一份**（不另起文件），更新「最后更新」。
- 版本管理：本目录是一个 git 仓库（见 `git log`）；大数据/敏感文件不入库。

> 说明：`SOP_AI辅助论文写作.md` 的**原始维护位置**是 `论文规范/`，这里保留一份同步副本，保证本库自成一体。
